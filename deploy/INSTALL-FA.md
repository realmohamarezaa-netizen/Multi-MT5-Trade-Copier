# نصب سریع — Multi-MT5 Trade Copier (ویندوز 10/11 x64)

## مهم — پیام «Windows protected your PC» (SmartScreen)

چون فایل‌ها **امضای دیجیتال پولی ندارند**، ویندوز موقع اجرای اولیه این پیام را نشان می‌دهد.
این یعنی «برنامه ناشناس است»، نه اینکه ویروس باشد. برنامه فقط روی `127.0.0.1` کار می‌کند.

**راه عبور (طبق همون پنجره آبی):**

1. در پنجره «Windows protected your PC» روی لینک **More info** کلیک کنید.
2. دکمه پایین از «Don't run» به **«Run anyway»** تغییر می‌کند — روی آن کلیک کنید. همین!

**راه‌های دیگر (اگر ترجیح دادید):**

- **راست‌کلیک روی فایل → Properties → تیک «Unblock» → OK** — بعد دیگر پیام نمی‌آید.
- یا در PowerShell داخل پوشه فایل: `Unblock-File .\MT5Copier-Setup.exe`
- برای نسخه ZIP: اگر با **7-Zip** باز و Extract کنید (به‌جای Explorer خود ویندوز)،
  فایل‌ها اصلاً علامت‌گذاری نمی‌شوند و SmartScreen نمایش داده نمی‌شود.
- اگر antivirus فایل را قرنطینه کرد: Restore کنید و پوشه را در Exclude بگذارید.
- برای اطمینان از سلامت فایل، هش SHA256 هر فایل در فایل `CHECKSUMS-SHA256.txt` داخل همان ریلیز هست.

> رفع کامل و همیشگی این پیام فقط با گواهی Code Signing (پولی، سالانه ~۲۰۰ تا ۵۰۰ دلار)
> ممکن است؛ اگر تهیه کنید، می‌توان فایل‌ها را در CI امضا کرد.

## روش ۱ — ZIP Portable (پیشنهادی: پنجره آبی SmartScreen اصلاً نمی‌آید)

1. فایل **`MT5Copier-Windows-x64.zip`** را دانلود و **Extract All** کنید.
2. فایل **`start-copier.bat`** را دابل‌کلیک کنید.
   - این لانچر اول علامت «فایل دانلودشده» را از همه فایل‌ها پاک می‌کند
     (Unblock-File)، بعد موتور را اجرا می‌کند — **پنجره آبی SmartScreen دیگر نمایش داده نمی‌شود.**
   - اگر یک پیام کوچک «Open File - Security Warning» آمد فقط یک بار **Run** بزنید.
3. داشبورد در مرورگر باز می‌شود: `http://127.0.0.1:8321`
4. **ترفند صفر-کلیک:** اگر ZIP را با **7-Zip** Extract کنید (نه Explorer ویندوز)،
   هیچ پیامی — حتی پیام کوچک Run — نمایش داده نمی‌شود.

> در هر دو روش، EXE تک‌فایلی است و داشبورد **داخل خودش** قرار دارد؛
> دیتابیس SQLite هم در پوشه `db` کنار همان پوشه اجرا ساخته می‌شود (کاملاً لوکال).

## روش ۲ — نصب با Installer (یک بار کلیک «More info» لازم دارد)

1. فایل **`MT5Copier-Setup.exe`** را دانلود و دابل‌کلیک کنید.
2. در پنجره آبی «Windows protected your PC»: **More info → Run anyway** (فقط همین یک بار).
3. نصب مثل هر برنامه ویندوزی انجام می‌شود (Program Files + میانبر دسکتاپ).
4. بعد از نصب، اجرای از میانبر دسکتاپ **هیچ پیامی ندارد** (فایل‌های نصب‌شده علامت دانلود ندارند).

## اتصال ترمینال‌های MetaTrader 5

1. فایل `MT5CopierEA.mq5` را در MetaEditor **هر ترمینال** باز و کامپایل کنید (F7).
2. EA را روی یک چارت در هر ترمینال بیندازید و AutoTrading را فعال کنید.
3. در داشبورد به ترمینال‌ها نقش **Master / Slave** بدهید و Start Copy را بزنید.

راهنمای کامل: پوشه `docs/` (هفت سند فارسی) — شروع با `docs/02-install-guide.md`

## اگر موتور اجرا نشد

- پنجره کنسول موتور را باز نگه می‌دارد و علت خطا را نشان می‌دهد.
- متن کامل خطا در فایل `db\engine-error.log` (کنار پوشه نصب) ذخیره می‌شود.
- رایج‌ترین خطا: اشغال بودن پورت‌های `8777` / `8321` توسط برنامه دیگر، یا بلاک شدن توسط antivirus.

## بیلد مجدد از سورس (اختیاری)

Python 3.11+ x64 نصب کنید و `deploy/worker/build_exe.bat` را اجرا کنید.
هر دو فایل Setup و Portable در Releases دقیقاً با همین روش و توسط
GitHub Actions (روی `windows-latest`) ساخته می‌شوند.
