# نصب سریع — Multi-MT5 Trade Copier (ویندوز 10/11 x64)

## ۱) دانلود و Extract

از صفحه [Releases](https://github.com/realmohamarezaa-netizen/Multi-MT5-Trade-Copier/releases/latest)
فایل **`MT5Copier-Windows-x64.zip`** را دانلود و روی سیستم خود Extract کنید.

## ۲) اجرای موتور و داشبورد

- فایل **`start-copier.bat`** را دابل‌کلیک کنید (یا مستقیماً `MT5CopierEngine.exe`).
- داشبورد خودکار در مرورگر باز می‌شود: `http://127.0.0.1:8321`
- اگر Windows Defender هشدار داد (فایل امضای دیجیتال ندارد):
  **More info → Run anyway**. موتور فقط روی `127.0.0.1` گوش می‌دهد،
  هیچ درخواستی به اینترنت نمی‌فرستد و رمز اکانت‌ها نزد خودش نگه نمی‌دارد.

## ۳) اتصال ترمینال‌های MetaTrader 5

1. فایل `MT5CopierEA.mq5` را در MetaEditor **هر ترمینال** باز و کامپایل کنید (F7).
2. EA را روی یک چارت در هر ترمینال بیندازید و «Allow DLL» لازم نیست — فقط AutoTrading فعال باشد.
3. در داشبورد به ترمینال‌ها نقش **Master / Slave** بدهید و کپی را Start کنید.

راهنمای کامل: پوشه `docs/` (هفت سند فارسی) — شروع با `docs/02-install-guide.md`

## ساختار پوشه بعد از Extract

| فایل / پوشه | توضیح |
|---|---|
| `MT5CopierEngine.exe` | موتور کپی (دیتابیس SQLite و داشبورد را کنار خودش می‌سازد) |
| `ui/` | داشبورد فارسی (توسط خود موتور سرو می‌شود) |
| `start-copier.bat` | اجرای موتور + باز شدن داشبورد |
| `MT5CopierEA.mq5` | اکسپرت اتصال ترمینال‌ها (سورس — در MetaEditor کامپایل شود) |
| `docs/` | مستندات فارسی: نصب، اتصال، تنظیمات، تست‌ها، عیب‌یابی |
| `db/` | در اولین اجرا ساخته می‌شود (دیتابیس محلی) |

## بازسازی EXE از سورس (اختیاری)

اگر خواستید خودتان بیلد بگیرید: Python 3.11+ x64 نصب کنید و `build_exe.bat` را از
مخزن (پوشه `deploy/worker`) اجرا کنید. ZIP آماده Releases دقیقاً با همین روش
توسط GitHub Actions (روی `windows-latest`) ساخته می‌شود.
