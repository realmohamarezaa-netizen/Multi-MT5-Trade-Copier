# ۰۲ — راهنمای نصب (Windows 10/11 x64)

## پیش‌نیازها

- ویندوز 10 یا 11 نسخه 64 بیتی
- یک یا چند ترمینال MetaTrader 5 نصب‌شده و لاگین‌شده (حساب Demo برای تست)
- برای ساخت EXE: یک بار Python 3.11+ و Inno Setup 6 (برای Installer). کاربر نهایی به هیچ‌کدام نیاز ندارد.

## مسیر ۱ — نسخه Portable (بدون نصب)

```bat
:: روی یک سیستم سازنده (یک بار):
cd worker
build_exe.bat            :: خروجی: worker\dist\MT5CopierEngine\MT5CopierEngine.exe
cd ..\installer
build_portable.bat       :: خروجی: installer\MT5Copier-Portable.zip
```

فایل zip را به سیستم معاملاتی منتقل و Extract کنید، سپس:

```bat
MT5Copier-Portable\start-copier.bat
```

این اسکریپت موتور را اجرا و داشبورد را باز می‌کند: `http://127.0.0.1:8321`

## مسیر ۲ — Installer

```bat
cd installer
build_installer.bat      :: خروجی: installer\Output\MT5Copier-Setup.exe
```

مراحل نصب:

1. `MT5Copier-Setup.exe` را اجرا کنید.
2. مسیر نصب را انتخاب کنید (پیش‌فرض: `C:\Program Files\MT5Copier`).
3. گزینه Desktop Shortcut و در صورت نیاز Autostart را علامت بزنید.
4. پس از نصب، برنامه را اجرا کنید؛ پنجره کنسول موتور لاگ‌های زنده را نشان می‌دهد.

نکته: موتور فقط روی `127.0.0.1` گوش می‌دهد؛ فایروال معمولاً هیچ پرسشی نمی‌کند. اگر پرسید، اجازه دهید (Allow) — ارتباط فقط داخلی است.

## نصب EA در ترمینال‌ها

برای هر ترمینال MT5 راهنمای `03-connect-terminals.md` را انجام دهید (چند دقیقه کار دارد).

## بعد از نصب

1. داشبورد: `http://127.0.0.1:8321`
2. در نمای «اتصالات» باید ترمینال‌ها با وضعیت سبز دیده شوند.
3. در نمای «مستر و اسلیوها» یک حساب را Master و بقیه را Slave کنید.
4. با حساب‌های Demo تست کنید؛ سپس نمای «آزمون‌ها» را برای اجرای ۱۷ تست پذیرش ببینید (در داشبورد مرجع).

## محل ذخیره داده‌ها

- دیتابیس: `<مسیر نصب>\db\mt5copier.db` (SQLite — فقط محلی)
- پشتیبان‌گیری: کافی است از همین فایل کپی بگیرید.

## حذف نصب

از Control Panel یا `Uninstall MT5Copier` در منوی استارت. فایل `db` در مسیر نصب باقی می‌ماند تا داده‌ها از دست نروند؛ می‌توانید دستی حذف کنید.
