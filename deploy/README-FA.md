## شروع سریع (۳ فرمان)

```bat
:: 1) ساخت EXE موتور (نیاز به Python 3.11+ یک بار برای ساخت)
cd worker && build_exe.bat

:: 2) ساخت نسخه Portable (یا Installer)
cd ..\installer && build_portable.bat

:: 3) اجرا
MT5Copier-Portable\start-copier.bat
```

سپس EA را در هر ترمینال MT5 نصب کنید (راهنما: `03-connect-terminals.md`)
و داشبورد را باز کنید: `http://127.0.0.1:8321`

## وضعیت صادقانه پروژه

- داشبورد کامل + موتور کپی + شبیه‌ساز: در همین مخزن اجرا و با ۱۷ تست پذیرش راستی‌آزمایی شده است.
- کد EA (MQL5) و موتور ویندوزی (Python): کامل و آماده کامپایل/اجرا روی ویندوز شماست؛ در این سندباکس لینوکسی امکان کامپایل EXE و اجرای MT5 وجود ندارد.
- اعداد تأخیر در محیط شبیه‌ساز، تأخیر واقعی خط‌لوله است؛ روی سیستم شما اعداد متفاوت (معمولاً کمتر) اندازه‌گیری می‌شود.
